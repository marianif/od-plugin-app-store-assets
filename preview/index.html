Upload is a decision, not a default.

The upload script is dry-run first. It reserves, uploads, commits and places only after an explicit confirmation, and it never submits for review.

01

Plan

One row per asset: spec, file, copy, order, placement target.

02

Compose

Fill the canvas, keep the HTML, render at 2× CSS points.

03

Validate

Mechanical blockers first; human critique for the judgment calls.

04

Place

Upload once to the Asset Library, reuse across localizations.

Built on the new Asset Library API. The old screenshot/preview set endpoints are deprecated in App Store Connect API 4.5.1. Specs and placement groups are resolved from /v1/appAssetLibraryRefData at runtime, so a new device size does not turn into a hardcoded list.
