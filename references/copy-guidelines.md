# Screenshot copy guidelines

The asset is a visual first, a sentence second. Apple's rule: use a **short
phrase that enhances the visual rather than describes it**.

## Shape of a good screenshot caption

- **2–6 words**, one idea, no period unless it is a full short sentence.
- Reads as a benefit or a verb, not a feature list.
- Works without the screenshot next to it; works even smaller in search.
- Does not repeat the app name (the product page already shows it).
- Written for a first-time visitor, not for the existing user.

Examples (finance app):

| Good | Bad | Why |
| --- | --- | --- |
| Know what you can spend | Trackly uses a monthly limit algorithm with 69% utilization | describes the visual instead of enhancing it |
| Every subscription, one place | Manage all your subscriptions and save $4.99/month | price claim |
| Log a expense in one tap | The fastest expense tracker — #1 in Italy | unverifiable claim |
| Your money, without the spreadsheet | Download now at trackly.app | CTA + URL |

## Banned in any asset copy

Hard blocks (validator P0):

- Currency amounts and price claims: `$4.99`, `€`, `£`, `free`, `sale`,
  `discount`, `% off`, `save X`
- URLs: `http://`, `https://`, `www.`, `app.example.com`
- Copyright/trademark symbols: `©`, `®`, `™`
- Apple recognitions: `Editor's Choice`, `App of the Day`, `Game of the Day`,
  `Apple Design Award`, `Featured by Apple`
- Other platforms/marketplaces: `Android`, `Google Play`, `Play Store`,
  `Samsung`, `Windows`, `Meta Quest`
- Unverifiable superlatives: `#1`, `best app`, `award-winning`, `millions of
  users` (unless the number is verifiable and the claim is allowed)

Soft warnings (P1/P2, human review):

- `new`, `now`, `finally` (time-bound; becomes stale)
- Exclamation marks, all caps, emoji as bullets
- Text longer than ~45 characters per line or more than 3 lines

## Localization

- v1 defaults to `en-US`. Additional locales are a follow-up run: keep the copy
  in the plan, not baked into an image.
- Leave room for +30% string growth (German, Italian). The canvas auto-fits the
  headline; test at 10% output width before uploading.
- Localize the **search results** asset per locale if it contains text. The
  header is text-free by design so one file serves every locale.
- Never machine-translate an idiom that carries the brand voice; write the
  locale version deliberately.

## Sequencing the set

A 5–8 screenshot set that tells one story:

1. The core promise (the one thing the app is for).
2. The daily action (the most-used screen).
3. The differentiator (what competitors do not show).
4. The proof (a real result/state, not a testimonial).
5. The breadth (secondary features, one screen each).
6. Optional: the delight / brand moment.

Order by value, not by app navigation order. The first two carry the search
result impression.
